全機能を対象に、コードの読み込み・計測用テスト（`tests/review/probes.test.ts`）・既存テストで調べました。

## 2. 問題が見つからなかった点（確認内容）

- 面積：靴ひも公式、坪換算（1坪＝3.305785㎡）、外周。テスト1〜5。
- 座標変換：下絵の画像座標⇄図面座標（縮尺・回転・平行移動）、基準寸法・PDF用紙寸法・DPI からの縮尺、2点での回転補正、相似変換による位置合わせ（鏡像なし）。下絵テストで往復誤差を確認。
- 画面座標と実座標の分離：描画モデルは図面座標で作り、表示変換は SVG の transform のみ。出力も同じモデルを用紙 mm に変換。
- 認証と権限（コード確認）：Supabase は RLS で `auth.uid() = owner` のみ読み書き可能、`save_project` は security invoker、下絵ストレージは利用者ID のフォルダに限定。クライアント側だけの権限判定はしていません。秘密情報はソースに含めず、公開してよい anon key のみ環境変数で受け取ります。
- PDF：ベクター出力（線・文字とも）。日本語フォントを埋め込み。

- 手動編集：追加・移動・回転・複製・削除・整列・等間隔、Undo/Redo（文字入力のまとめ、ドラッグ1回＝1履歴）
- 自動保存：デバウンス、保存中の編集、失敗時の再試行、版の作成条件
- 保存・再読込（ローカル保存）、壊れたデータの検出・補正
- iPhone 操作（Chrome のエミュレーション。iPhone SE / 14 / 15 Pro Max / 横向き / iPad mini）：ピンチ、2本指移動、1本指で枠移動、回転ハンドル、テンキー、全体表示、選択解除、最大化、ページがズーム・スクロールしないこと
- 下絵取込：PDF・PNG・JPEG、基準寸法、縮尺合わせ、回転補正、透明度、頂点配置、頂点間距離、寸法の確認・修正後に作成、元画像と図面データの別保存、画像以外の拒否
